# 📋 GitHub Kanban Board Guide

## **Why We Use This Board**

### **The Problem Without It**
- 4 developers working on the same project
- No one knows who's doing what
- Two people code the same thing → **merge conflicts** 😱
- Hard to track progress

### **The Solution: Kanban Board**
A **shared visual board** where everyone sees:
- ✅ What's already done
- 🔄 What someone is working on RIGHT NOW
- 📝 What needs to be done next
- 🔍 What's waiting for review

**Result:** No confusion. No duplicate work. Everyone knows the status.

---

## **How It Helps us**

| Problem | How Board Fixes It |
|---------|-------------------|
| Two people code same feature | Card shows someone already working on it |
| Can't find who to ask | See who's assigned to each card |
| Don't know what to work on next | Check **Ready** or **Backlog** columns |
| Team lead doesn't know progress | See all cards moving through columns |
| Merge conflicts from duplicate work | Prevents it before it happens |

---

## **What is the Kanban Board?**

A **visual way** to track your work. Cards move from left → right as you progress.

```
[Backlog] → [Ready] → [In Progress] → [In Review] → [Done]
```

---

## **How to Create a Card**

1. Go to your **GitHub repo** → **Projects** tab
2. Click **"Dashboard Project"** board
3. Click **"+ Add item"** in the **Backlog** column
4. Type your task name (e.g., "Add Label Component")
5. Press **Enter**

---

## **How to Assign Yourself**

1. Click the card you created
2. On the right panel, click **"Assignees"**
3. Select **your name**
4. Close the panel

---

## **Move Your Card**

**As you work:**

- **Ready** → You're about to start
- **In Progress** → You're working on it now
- **In Review** → Ask team lead to review
- **Done** → Merged & finished! ✅

Drag the card between columns or click it and change status.

---

## **Example Workflow**

1. Create card: *"Create Label Component"*
2. Assign to yourself
3. Move to **In Progress** when you start coding
4. Commit & push your branch
5. Create a **Pull Request**
6. Move to **In Review**
7. Team lead reviews → Merges
8. Move to **Done** ✅

---

## **Tips**

- **One card = One feature** (don't mix multiple tasks)
- **Update status** as you work (keeps team in sync)
- **Add comments** on the card if you need help
- **Ask in the card** instead of Slack — keeps history
